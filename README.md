
# Fed-GraphSAGE: Lightweight Federated Graph Learning for Privacy-Preserving Supply Chain Optimization

This proposed system is designed as a privacy-preserving supply chain optimization framework using federated graph learning. It applies a lightweight Fed-GraphSAGE model to predict supply chain quantity-related outcomes while keeping carrier-level data partitions separated as federated clients. The framework combines supply chain data preprocessing, carrier-based federated partitioning, graph construction, GraphSAGE learning, FedAvg with momentum, baseline comparison, ablation analysis, and result visualization.

Different parts of the pipeline are included in the notebook so that future researchers can run, modify, and extend the framework for supply chain analytics, federated learning, and graph neural network-based optimization.

## Overview

The framework uses:

- Carrier-based federated clients
- Graph construction using cosine similarity
- Lightweight 2-layer GraphSAGE model
- Federated averaging with momentum
- Baseline comparison with LR, XGBoost, GBDT, LSTM, and GNN
- Ablation study
- Multi-round federated training
- Result plots and output files for paper use

## Installation

### Step 1: Clone the Repository

Clone this repository to your local machine:

```bash
git clone[ https://github.com/Zferdus/Supply-Chain.git](https://github.com/Zferdus/Supply-Chain)
cd Fed-GraphSAGE-SupplyChain
````

### Step 2: Create Python Environment

You may use Google Colab directly. For local use, create a virtual environment:

```bash
python -m venv venv
```

Activate the environment:

For Windows:

```bash
venv\Scripts\activate
```

For Linux/Mac:

```bash
source venv/bin/activate
```

### Step 3: Install Dependencies

Install the required Python packages:

```bash
pip install -r requirements.txt
```

If `torch-geometric` gives installation issues, install it according to your PyTorch and CUDA version from the official PyTorch Geometric installation guide.

## Dataset

## Run It

Open the notebook:

```text
FedGraphSAGE_main.ipynb
```

Then run all cells sequentially.

The notebook will:

1. Install required packages.
2. Download the supply chain dataset.
3. Clean and preprocess the data.
4. Partition the data by carrier as federated clients.
5. Build graph data using cosine similarity.
6. Train the Fed-GraphSAGE model.
7. Evaluate the model on the global test set.
8. Run ablation experiments.
9. Run baseline models.
10. Generate figures and result files.

## Main Outputs

After successful execution, the notebook generates:

* Final MSE, RMSE, and SD values

* Ablation study results
* Training and validation loss curves

* Comparison bar chart
* Saved model file

## Troubleshooting

### Dataset Not Downloading

Make sure the internet connection is active. If KaggleHub requires authentication, log in to Kaggle or configure your Kaggle API token.

### Torch Geometric Installation Error

Install PyTorch Geometric based on your PyTorch version. Google Colab is recommended for easier setup.

### XGBoost Error

Install XGBoost manually:

```bash
pip install xgboost
```

### Memory Error

Reduce local epochs, reduce the number of federated rounds, or run the notebook in Google Colab.

### Slow Performance

Use GPU runtime in Google Colab:

```text
Runtime > Change runtime type > GPU
```
